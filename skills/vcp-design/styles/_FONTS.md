# 字体场景速查（styles/_FONTS.md）

> ## ⚠️ Kimi Code 适配版须知（先读）
> **本环境仅以下 7 款字体已全局注册、保证可用**：`Lanxi-WenKai`（楷书·正文）、`Lanxi-WenKaiLight`（楷书·细）、`Lanxi-MaShanZheng`（手写楷）、`Lanxi-HeiTi`（黑体）、`Lanxi-HeiTiLight`（黑体·细）、`Lanxi-HeiTiBold`（黑体·粗）、`Lanxi-GreatVibes`（英文花体）。
> 直接写 `font-family:'Lanxi-WenKai'` 即命中，**无需 @font-face**。
> 下表为 dsh 全量库（25+ 款）的场景指南——**未在上列 7 款中的名字会静默回退系统字体**：选字体时先在上表 7 款里找最接近的（如「数据·理性」→ `Lanxi-HeiTi`/`Lanxi-HeiTiLight`；「文学·书信」→ `Lanxi-WenKai`；「古风题花」→ `Lanxi-MaShanZheng`；「英文花体」→ `Lanxi-GreatVibes`），找不到就用系统字体栈兜底，**不要写未注册的名字**。

## 铁律（字体运用三戒）

1. **克制**：单帖最多 1-2 款艺术字体；正文默认系统无衬线（数字用衬线 `tabular-nums` 造精度）；**宋体例外——warm-minimal 锁定风格指引正文 `Lanxi-可宋`（先生实证 15px 清晰雅致），其余场景正文仍系统无衬线**。
2. **对味**：繁体字库配繁体内容；数据场景不硬上书法体；萌系场景不上瘦金书——字体的气质要和内容的气质匹配（「温度与精度的配比」）。
3. **防呆**：渲染器已自动给文字声明加 !important（boost 机制抗皮肤覆盖），@font-face 已被保护不会被误伤——无需手动加 important，也不要删掉 @font-face。
4. **手写感看来源，不看分类**：楷书（WenKai/颜宋/品宋）是电脑笔法生成的机械体——形似楷、无手气，**不算手写**；要「人手感」必须选手写/行书类（春兰茅坤/自由浪漫/鱼尾行书）。选字先问一句：这温度，是哪里来的？
